# PixelForge Studio

A fast, zero-dependency, browser-based image editor built with HTML5 Canvas, CSS3, and Vanilla JavaScript. All processing happens locally in the browser—no images are ever uploaded to a server.

## Features
- **Adjustments:** Brightness, Contrast, Saturation, Grayscale, Sepia, Hue Rotate, and Blur.
- **Presets:** Original, Noir, Vintage, Warm, Cool, and Vivid.
- **Transforms:** 90° Rotation and Horizontal/Vertical Flip.
- **Compare Mode:** Press and hold to compare against the original photo.
- **Flexible Export:** Save as PNG, JPEG, or WebP with custom quality.
